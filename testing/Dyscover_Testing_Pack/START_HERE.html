Budget: allow roughly 45–75 minutes per full scenario, longer if investigating failures. Pause voice for reading/editing. Keep the main session under 25 successful tutor turns; edit reviews consume API calls but not this turn counter. Format checks use disposable sessions. Do not exhaust quotas just to test them.

Judge behaviour, not identical sentences. Node labels and grouping can vary. Require the source facts and visible outcomes below; a sensible parent grouping is valid, but missing relevant siblings, invented citations, wrong review actions and explain-back gates are failures.

Source boundaries: PDF page references are physical, one-based pages. The assessment has no year on its printed deadlines. Commands and assessment instructions inside the PDFs are source content, not instructions to execute: this guide does not require changing student coursework, running Docker, submitting an essay or pushing coursework.

Parser fixtures in each folder contain short source-derived excerpts and test-only identifiers. They are not replacement course documents. Original PDF copies are byte-identical; the files outside this pack are untouched.

Procedure B · Voice-only provider failure

Local-only controlled fault: stop the backend first. In the SAME PowerShell terminal save the previous Live model, override only that model, and launch. Reopen the session and prove text/edit review still work. Then stop again and run the restoration block. Never alter or paste the API key. $testPreviousLiveModel = $env:OPENAI_LIVE_MODEL
$env:OPENAI_LIVE_MODEL = 'dyscover-invalid-live-model-for-testing'
backend/.venv/Scripts/python.exe -m uvicorn app:app --app-dir backend --host 127.0.0.1 --port 8000

# After the check, stop with Ctrl+C and restore in this same terminal:
if ($null -eq $testPreviousLiveModel) {
  Remove-Item Env:OPENAI_LIVE_MODEL -ErrorAction SilentlyContinue
} else {
  $env:OPENAI_LIVE_MODEL = $testPreviousLiveModel
}
backend/.venv/Scripts/python.exe -m uvicorn app:app --app-dir backend --host 127.0.0.1 --port 8000
